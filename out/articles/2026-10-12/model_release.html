今天模型发布板块最值得看的不是某一个模型，而是一个品类在 24 小时内挤进了三家玩家：微软 Decision-1、Cloudflare Clef-omni、vLLM Semantic Router Decision 3.0。它们的共同点是都不生成文本，只做选择、判断与打分——这等于把「生成」之外的判断能力单独拆成了一层产品。另一条线是小米公开 MiMo-V2.6 的后训练账单：单次 RL 260 万美元、每步 37 亿 token，把大模型的后训练从算法问题变成了资本开支问题。这两件事指向同一个趋势：模型的能力正在被切分、定价和商品化。

微软 Decision-1 入场，决策模型成了独立赛道

微软推出 Decision-1，定位非常明确：不做对话，不做生成，专攻选择题、是否题与打分类判断任务。这直接切进了正在快速升温的「决策模型」赛道，与 vLLM、Cloudflare 等新玩家同场竞争。

关键点在于任务形态而非参数规模。选择题、二分类、打分这三类输出，恰好覆盖了路由、风控、内容审核、A/B 判优等大量线上系统里最高频的调用场景——这些场景过去默认用通用大模型来跑，成本高、延迟大，而且输出格式不稳定。

为什么重要：一家云厂商亲自下场做「只判断不生成」的模型，说明这个位置被验证有独立价值。对开发者而言，接下来要做的判断是——继续用通用模型加 prompt 硬扛，还是把判断逻辑迁移到专用决策模型上。前者的迁移成本低，后者的单位成本低，窗口期不会太长。

Cloudflare 开源 Clef-omni：一次调用给音视图文打分

Cloudflare 发布 Clef-omni，Apache-2.0 许可，基于 Qwen3-Omni-30B-A3B 构建。它的能力是：一次调用即可对文本、图像、音频、视频做决策打分，输入价格低至每百万 token 0.15 美元。

关键点有两个。第一是多模态统一入口，过去要判断一段视频或一段音频是否合规，往往需要先转写再做文本判断，链路长且误差累积；现在是单次调用。第二是价格——0.15 美元/百万 token 的输入定价，明显是按「被高频调用」来设计的，而不是按「偶尔生成一段长文」来设计的。

为什么重要：决策模型和生成模型的商业模式完全不同。生成模型按输出价值收费，决策模型按调用次数收费，因此单价必须压得极低。Apache-2.0 加开源权重，也意味着有能力的团队可以直接自托管，把边际成本压到接近零。这条路线如果跑通，会挤压掉一部分「用大模型做分类」的存量需求。

小米 MiMo-V2.6：一次 RL 后训练烧掉 260 万美元

小米公开了 MiMo-V2.6 的「规模化强化学习」路线，并罕见地摊开了账单：单次 RL 后训练成本达 260 万美元，每步消耗 37 亿 token。

关键点不是模型本身，而是这组数字。后训练成本长期是各家闭口不谈的部分，公开案例极少，导致外界很难判断「复现一个强推理模型」到底需要多少预算。260 万美元 / 次这个量级，意味着一次失败的 RL 实验就烧掉一家中型创业公司相当比例的年预算，而 RL 恰恰是需要反复试错的环节。

为什么重要：如果后训练的真实成本结构是这样，那么前沿模型的竞争门槛就不在算法创意上，而在能不能承受多次失败。这会带来两个后果——头部厂商的资本优势被进一步放大；同时开源社区会更依赖已经调好的后训练配方，而不是从零复现。小米愿意公开这组数据，本身也是一种信号：规模化 RL 是它想被看见的能力标签。

GPT-6.1 Sol 极速版上线，快是真的，贵也是真的

OpenAI 上线 GPT-6.1 Sol 极速版，速度提升明显，但价格高于此前的 Astra。社区的反馈很直接：连 500 美元档的套餐都撑不过一天。

关键点是定价分层的方式变了。过去模型定价主要按能力档位区分，现在多了一个新维度——推理速度。极速版把「低延迟」单独拿出来卖，这在 agentic 工作流里是有真实需求的：一个 agent 一次任务可能发起几十上百次调用，延迟直接决定任务能否在可接受的时间内完成。

为什么重要：速度溢价会不会被市场接受，取决于替代方案是否存在。如果开源模型或决策模型能在具体环节上以更低成本完成同样的判断，那么「为速度付费」的意愿就会被压低。今天的板块里三家决策模型同时出现，某种程度上正是对这个价格问题的回应——不是所有调用都需要最强的模型，也不是所有调用都值得付速度溢价。

Odyssey-3 开放免费试玩，世界模型回到「可玩性」

新的生成式世界模型 Odyssey-3 发布并开放免费体验，支持实时交互式模拟，演示场景包括雪地里的猫咪、厨房等。

关键点是交互式与实时。世界模型这条路线一直存在一个验证难题：用视频画质或 benchmark 分数来衡量，很难反映模型是否真正理解了物理与因果。而「能不能实时响应操作并保持场景一致」是一个更难作弊的测试——你按一下方向键，模型要么维持住世界的连贯性，要么立刻露馅。

为什么重要：免费开放试玩是一种聪明的验证方式，把评测权交给大量用户的直觉。对做 agent 和具身智能的团队来说，世界模型的真正价值不在演示，而在于能否作为低成本的环境模拟器，替代一部分真实世界的试错。Odyssey-3 现在还处在演示阶段，但方向值得跟踪。

GPT-4o 下架 8 个月，API 快照进入停用倒计时

初代 GPT-4o 的 API 快照即将正式停用。值得注意的是，这个模型已经下架八个月，但仍有开发者在发起「拯救 4o」行动。

关键点是「八个月」这个时间差。从产品下架到 API 停用，中间留了相当长的缓冲期，这说明厂商清楚迁移是有成本的；但仍有用户在这段时间里组织起来反对，说明迁移成本比预期更高。原因通常不是能力差异，而是行为差异——同样的 prompt，换模型后输出风格、格式稳定性、拒答边界都会变，依赖它的下游系统需要重新调优。

为什么重要：这对做产品的人是一个提醒。模型的人格与稳定性本身构成一种隐性锁定，用户黏的不一定是能力最强的那个模型，而是行为最可预测的那个。同时也说明，把业务逻辑深度绑定在单一模型的具体行为上，是一项需要主动管理的技术债。

vLLM 开源 Decision 3.0：五个只打分不生成的小模型

vLLM Semantic Router 发布 Decision 3.0，包含 0.8B 到 27B 共 5 个模型，全部 Apache-2.0 许可，全部为多模态。它们的定位很纯粹：只做选择与打分，不生成文本。

关键点是尺寸梯度。0.8B 这一档意味着可以在极低成本、甚至边缘侧完成初步路由判断，而 27B 档则处理更复杂的多模态决策。这种「同一能力、多个尺寸」的发布方式，本身就是为生产环境设计的——大部分请求不需要动用最大的那个。

为什么重要：这是对 LLM-as-judge 模式的一次正面替代。用通用大模型做评审和路由，成本高、延迟大，而且评判标准不稳定。专用小模型在固定任务上可以做到更快、更便宜、更一致。如果这类模型成熟，模型路由层会从「工程技巧」变成「标准组件」，而这正是 vLLM 这类基础设施项目最擅长占住的位置。

OrcaCyber Zero 1.5：100 万上下文的安全专用模型

OrcaRouter 发布网络安全专用模型 OrcaCyber Zero 1.5，支持 100 万 token 上下文，并宣称在 Cybench 上达到 100%、在 CVE-Bench 子集上达到 95.8%。

关键点是长上下文与垂直领域的组合。安全场景的输入天然很长——一整个代码仓库、一份完整的日志、一堆依赖清单，短上下文模型只能靠切片和拼接，容易丢失跨文件的关联。100 万 token 让「把整个项目一次性喂进去做审计」成为可行操作。

需要说明的是，上述两项指标均为官方宣称，尚无独立复现，Cybench 满分这类结果在实际使用中通常会有明显折扣。为什么仍然重要：安全是少数几个「错误成本极高、因此愿意为专用模型付费」的领域，也是垂直模型最容易建立壁垒的方向之一。它的真实价值不取决于 benchmark 分数，而取决于在真实代码库上的误报率。
