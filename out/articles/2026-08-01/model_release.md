# GPT-5.6 发布，性价比战升温

8 月 1 日，OpenAI 正式发布 GPT-5.6，官方叙事直接落在“价格—性能前沿”上。这是今天最值得关注的信号：模型竞争的重心，正在从单点能力上限转向单位成本能买到的智能。同一天，DeepMind 发布机器人模型，DeepSeek 开源新权重，三家动作合在一起，足以看清行业当前的主攻方向。

## OpenAI 发布 GPT-5.6，主打性价比提升

**是什么**：OpenAI 宣布推出 GPT-5.6，官方以“价格—性能前沿”为主线，强调新版本以更低成本带来更强能力。

**关键点**：性价比成为官方卖点，而非某一个单一的基准分数。对 API 调用方而言，同样预算可以处理更多请求，或直接把手头的任务升级到更高档位的模型。

**为什么重要**：同日 DeepSeek V4 Flash 0731 开源并给出性价比分析，闭源与开源同一天亮出各自的成本与能力组合。GPT-5.6 的发布，等于把成本效率确认为新一代模型的关键竞争标签。

> 原文：[OpenAI 官方公告](https://openai.com/index/advancing-the-price-performance-frontier-with-gpt-5-6/)

## DeepMind 发布 Gemini Robotics 2，赋予机器人全身智能

**是什么**：DeepMind 发布 Gemini Robotics 2，面向具身智能（embodied AI）场景，重点提升全身协调、物体操控与空间理解能力。

**关键点**：这次升级的重心在动作层：全身协调解决多关节同步控制，物体操控解决“动手”能力，空间理解解决“在哪里做”的判断。三者组合，才能支撑真实环境中的完整操作。

**为什么重要**：模型能力正在从文本与图像走向物理世界的行动决策。对机器人研发团队来说，这类模型可能成为新的控制底座，降低技能开发门槛，而不再需要从零训练每个动作。

> 原文：[DeepMind Blog](https://deepmind.google/blog/gemini-robotics-2-brings-whole-body-intelligence-to-robots/)

## DeepSeek V4 Flash 0731 开源，性能价格分析出炉

**是什么**：DeepSeek V4 Flash 0731 的权重在 Hugging Face 上线，Artificial Analysis 随即发布性能与价格分析，性价比表现受到关注。

**关键点**：模型权重完全开源，开发者可以自行部署，不依赖单一 API 渠道。Artificial Analysis 的跟进，等于在发布当天给出了第三方参照系。

**为什么重要**：在 OpenAI 发布 GPT-5.6 的同一天，DeepSeek 给了另一条路径：不等待闭源厂商降价，而是把模型拿回自己手里。模型竞争的价格锚点，正同时被闭源与开源两端改写。

> 原文：[Hugging Face 模型页](https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash-0731)

## 结语

今天的记忆点只有一句：模型竞争的看点，不再只是谁更强，而是同样的钱能买到多少智能。接下来值得观察的，是开发者会用脚投票，把预算投向闭源 API 还是开源权重。
